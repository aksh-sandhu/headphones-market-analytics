# 🎧 Headphones Market Analytics Dashboard

An interactive data analytics dashboard built using **Python, SQL, Streamlit, and Plotly** to analyze the online headphones market. The dashboard provides insights into pricing, brands, product features, and market trends using data scraped from Smartprix.

## 🚀 Live Demo

🔗 https://headphones-market-analytics.onrender.com/
🔗 https://headphones-market-analytics.streamlit.app

## ✨ Features

### 📊 Overview
- Total products, average price, average rating, and total brands
- Brand market share
- Wired vs Wireless distribution
- Product distribution across price segments
- Brand-wise average price analysis

### 📈 Market Insights
- Product distribution across price segments
- Bluetooth version distribution
- Price vs Rating analysis
- Segment-wise market analysis
- Interactive visualizations

### 🏷️ Brand Analysis
- Analyze individual brands
- Product count
- Connectivity distribution
- Microphone availability
- Product type distribution
- Fit type analysis

### 📋 About Dataset
- Dataset summary
- Number of products
- Number of brands
- Database information
- Random dataset samples

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/aksh-sandhu/headphones-market-analytics.git
```

Go to project folder

```bash
cd headphones-market-analytics
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
